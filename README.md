# j-poc.github.io

The public site for Holdout, served by GitHub Pages at https://j-poc.github.io.

Holdout has not launched yet. This site is plain Jekyll, HTML and CSS, with no JavaScript framework.

- `_layouts/default.html` is the one layout. Every page uses it.
- `assets/style.css` has the styles, with light and dark modes.
- `_data/nav.yml` is the menu.
- `content/` holds pages added by Holdout fixes (one markdown file per fix). A file `content/<slug>.md` is served at `/<slug>/`.
